## Improvements shipped after the Roomcast rehearsal (all with tests, suite green)

- **doctor warns when a Mac can sleep** (reads `pmset`), the cause of four runner drops.
- **Status page flags silent agents**: "idle (no heartbeat for 4 min)" instead of a stale "idle".
- **Synthesized reports keep the CLI's error** (a spawn failure no longer reads "Report missing").
- **Planner sizing rule**: pages that talk to an API or need a browser check are M, not S.
- **Resumed branches are rebased onto main** before the run; conflicts go into the worker's brief.
- **Claim watchdog**: a run whose task was handed to another agent is stopped (whole process group), no double work.
- **Plugins listed once per process** instead of three times per task.
- **Merger reopens a PR** when the linked one is stale (old runner, repeated branch names).
- **Self-improvement retro**: at every completed milestone, serve writes `docs/LESSONS.md` (read by every worker and the planner) and `.swarm/tuning.yaml` (safe config changes merged over config.yaml), plus a report in `docs/retro/`. Already fired for M1 and M2 on the tryout board.
- **`swarm night`**: unattended cycles that each add one small app as a milestone, answer blocking questions, retro, and write a cycle log to `docs/night/`.
- **Packaging**: prompts, template and skills now ship inside the package (`pip install` from git works without the source tree).
