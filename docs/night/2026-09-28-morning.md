## Edge cases found and fixed while the cycles ran

- **Cut dependency**: its dependents waited in Backlog forever, so the milestone and its retro never finished. A cut dependency now counts as resolved and the worker is told to build without it.
- **Unknown dependency id** (a typo): blocks the task with one question instead of waiting forever.
- **Dependency cycles**: detected (linear-time) and blocked with one question.
- **Board or network outage**: `swarm run` used to exit on the first error; it now logs, backs off from 15 s to 5 min, and keeps going. `swarm serve` retries its startup lock the same way.
- **Nobody available** (Claude over its soft cap, Codex offline): tasks used to fall back to any configured agent, dead ones included. They now go to a live agent first.
