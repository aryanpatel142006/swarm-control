Smaller recurring items fixed in the same commit:
- `swarm restart` used `pgrep -f "swarm run"`, which also matched `caffeinate -dims swarm run` (SIGUSR1 terminates caffeinate, so the runner lost its sleep guard) and any shell whose command line contained the words (the after_restart.sh self-match, Oct 10). It now signals only Python/`swarm` processes whose subcommand is `run`.
- `swarm assign` left a conflicting `host:` pin, so T-362/T-364/T-354 sat unclaimed 40 min after an assign to claude-a (Oct 10). Assign now moves the pin to the new agent's host and says so.
- The test fixture's event window was a fixed date; once Oct 11 passed, two status tests went red. It is relative to now.
