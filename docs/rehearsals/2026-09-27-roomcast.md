Where the waste came from, and what changes:

1. **Haiku on frontend pages.** T-013 burned three Haiku runs at the 30-turn limit before anything was written; T-014 did the same once. Fix shipped: a resume after max turns / timeout steps the model up a tier. Config change: `type_model_overrides.claude.frontend.low: sonnet`, so frontend never runs on Haiku even at low importance.
2. **Shared docs edited by several tasks.** T-003, T-011 and T-013 all touched docs/DESIGN.md; T-002 and T-007 both wrote docs/CONTRACTS.md. That produced rebase conflicts, a "changes requested" bounce and an extra Opus attempt on T-011 ($5.58, the most expensive task). Change: the planner keeps shared docs in exactly one task's scope per milestone (the lint already flags overlaps; make it a hard rule in the planner prompt) and worker rules say "do not edit docs outside your scope".
3. **Forced reviews on low tasks.** T-013 and T-014 were low importance but got three and two review rounds because `out_of_scope` forces a review. Keep the rule (it caught real drift), but the scope drift itself is item 2.
4. **The stale-PR bug** cost the most in wall clock: four tasks "merged" into nothing, an hour of recovery. Fixed; no cost in tokens beyond the re-runs of T-005.
5. **Teammate's runner** dropped four times (laptop sleep). Each drop reaped a task after 10 min and rerouted it; one duplicate run (T-008). Rule for the event: `caffeinate -dims` and power for both laptops; and the hand-back improvement noted at 05:0x.
6. **Ledger and branch names collide across board resets.** `swarm usage` mixed the old project's T-019 with the new one. Change: ledger rows carry the board id and `swarm usage` filters on it.

What worked and should stay: review by a different model family (caught the missing verification note, the missing browser check, the scope drift), 96% cache hit rate (the per-task prompt trimming and plugin switch-off paid off), tier routing (Opus only on critical/high frontend), rate-limit cooldown + reroute (Gemini), orphan reaping + reroute (teammate offline), question relay (Q-001…Q-007 answered from the CLI, agents resumed on their branches).
