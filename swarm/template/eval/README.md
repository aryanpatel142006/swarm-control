Acceptance tests and benchmarks. `eval/acceptance` runs in `verify_full.sh`; `eval/benchmarks` publishes summaries. Generated fixtures go to `eval/fixtures/generated/` and raw results to `eval/results/`: both are gitignored and shared from the main checkout into every worktree by `scripts/setup_worktree.sh`, so they survive the task that made them. Unit tests never read them (a fixture that appears must not change a test's outcome).
